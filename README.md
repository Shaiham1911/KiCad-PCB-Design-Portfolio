# KiCad PCB Design Portfolio

A collection of **9 manufacturing-ready 2-layer and 4-layer PCB designs** created in **KiCad**, verified with Design Rules Checker (DRC), and packaged with fabrication outputs.

## Standard Deliverables per Project
Each project folder includes:
- `schematic.pdf` — Full circuit schematic
- `layout_2d.png` — 2D PCB layout view
- `3d_top.png` — 3D rendered board view
- `gerbers.zip` — Fabrication Gerbers and drill files
